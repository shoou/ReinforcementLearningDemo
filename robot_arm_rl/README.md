# 强化学习 × 具身智能：机械臂安全分拣

需要开源三维物理仿真及更多工位时，参见 [PyBullet 七关节机械臂版](pybullet_3d/README.md)：四个取件位、四个料箱，覆盖 16 种订单，并提供三维动画和电机回放验证。

场景是一个**索引式输送带分拣工位**：输送带将包裹停在两个预设取件位之一，视觉或上游系统给出目标料箱，机械臂负责抓取、避开固定设备、将包裹放到指定料箱。案例使用二维双关节平面模型，适合课堂展示“策略学习 + 机械约束 + 任务执行”的关系。

## 直接运行

只需要 Python 3.9+，无需安装第三方包：

```bash
python3 robot_arm_rl/arm_sorting.py
```

运行后用浏览器打开 [output/demo.html](output/demo.html)，可选择四种订单、播放/暂停、拖动时间轴，观察机械臂运动、包裹状态、禁入区、训练成功率与动作统计。`output/metrics.json` 保存同一批指标。已有一份按默认参数生成的结果，可直接打开页面。重新训练时可指定 `--episodes`、`--seed`、`--output`。

## 强化学习设计

| 要素 | 本案例 |
| --- | --- |
| 状态 | 取件位编号、料箱编号、抓取/放置阶段、两个关节的离散角度 |
| 动作 | 每次让一个关节正转或反转 10°，每步 0.25 秒 |
| 任务 | 从待机位出发，到取件位抓取，再到目标料箱释放；上限 90 步 |
| 奖励 | 每步时间惩罚，向阶段目标靠近时奖励，远离时惩罚；抓取和放置额外奖励；触发安全联锁或超时受罚 |
| 学习 | ε-greedy Q-learning，折扣系数 0.98，学习率 0.25；训练中随机抽取四种订单 |

机械臂两节杆长为 0.27 m 和 0.23 m。角度被限制在离散关节范围内。固定设备以矩形表示，环境对两节连杆和动作期间的中间姿态采样，预留 10 mm 安全余量；越界或碰撞动作由安全联锁拦截，机械臂保持原位。夹爪只在末端到达预设工位时自动抓取或释放。它是任务层的简化，不模拟接触力和抓取失败。

默认种子 42、12,000 回合训练的一次结果：最后 100 个训练回合成功率 100%；四种订单的贪心回放均成功，用 35、36、37、38 步，分别等于本离散模型的最短安全路径长度。这**只覆盖四种预设订单和这个确定性仿真**，不能当成泛化成功率或实体机器人可靠性。

## 与真实产线的对应和边界

本案例对应真实应用中的取件位标定、订单指派、路径规划、禁入区与安全联锁等环节。为了让课堂案例在普通电脑上离线运行，工位位置、尺寸、节拍、障碍物和奖励均为**合成教学参数**；抓取点已知，输送带在动作期间静止，不含深度相机、逆运动学误差、动力学、驱动器限速、夹爪力控、负载变化和人员进入工位等因素。

若要迁移到实际机械臂，应基于设备手册和实测数据建立三维模型、标定相机和工具坐标系，加入连续轨迹的碰撞与速度/加速度约束，并经过仿真回放、实体离线测试和独立安全控制器验证。本示例生成的策略不能直接连接机器人控制器。

## 课堂探索

1. 将禁入区扩大，比较最短安全路径、训练速度和成功率。
2. 将动作上限从 90 步降到 40 步，观察超时惩罚与规划效率。
3. 关闭奖励中的距离变化项，比较稀疏奖励对学习速度的影响。
4. 添加随机工件偏移与抓取失败，讨论观测、重试和仿真到现实的差距。
